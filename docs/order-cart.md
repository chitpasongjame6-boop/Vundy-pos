# Order Cart

เพิ่มระบบตะกร้าในหน้า `/orders/new` เพื่อให้ออเดอร์ออนไลน์ 1 บิลมีสินค้าได้หลายรายการ

## การใช้งาน

- สแกน `SKU / Barcode` แล้วระบบจะเพิ่มสินค้าเข้าตะกร้าออเดอร์ทันที
- ถ้าสแกนสินค้าตัวเดิมซ้ำ ระบบจะเพิ่มจำนวนในรายการเดิม
- ถ้าสแกนสินค้าตัวใหม่ ระบบจะเพิ่มเป็นอีกรายการในออเดอร์เดียว
- สามารถเลือกสินค้าจาก dropdown, ใส่จำนวน, แล้วกด `ເພີ່ມ`
- ในตะกร้าสามารถกด `+` หรือ `-` เพื่อปรับจำนวน และกดลบรายการได้
- ปุ่มสร้างออเดอร์จะกดได้เมื่อมีสินค้าในตะกร้าอย่างน้อย 1 รายการ

## การบันทึก

หน้า form ส่งข้อมูลเป็น array:

- `productVariantKey[]` รูปแบบ `productId::variantId`
- `quantity[]` จำนวนของสินค้าตามแถวในตะกร้า

`createOrder` จะรวมรายการซ้ำก่อนบันทึก เช่น สแกนสินค้าเดิม 3 ครั้ง จะกลายเป็นสินค้าเดียวจำนวน 3

## การคำนวณและสต็อก

ก่อนสร้างออเดอร์ ระบบจะ:

- ตรวจว่าสินค้าทุกตัวมีอยู่จริงและเปิดขายอยู่
- ตรวจว่าสต็อกแต่ละ variant เพียงพอ
- คำนวณยอดขายรวม
- คำนวณต้นทุนรวม
- คำนวณกำไรรวม
- ตัดสต็อกทุกสินค้าในตะกร้า
- ตั้งสถานะออเดอร์ใหม่เป็น `PENDING_PACK`
