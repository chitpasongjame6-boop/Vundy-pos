# POS Module

ໜ້າຂາຍໜ້າຮ້ານແຍກຈາກອໍເດີອອນລາຍ ເພື່ອໃຊ້ສະແກນສິນຄ້າ, ຄິດໄລ່ເງິນ, ຕັດສະຕ໋ອກ ແລະປິ້ນບິນໃຫ້ລູກຄ້າ.

## ການໃຊ້ງານ

- ເຂົ້າເມນູ `ຂາຍໜ້າຮ້ານ`
- ສະແກນ SKU / Barcode ລົງຊ່ອງສະແກນ; ຖ້າລະຫັດກົງກັບ SKU ລະບົບຈະເພີ່ມເຂົ້າຕະກ້າອັດຕະໂນມັດ
- ເລືອກສິນຄ້າຈາກ dropdown ແລ້ວລະບົບຈະເພີ່ມເຂົ້າຕະກ້າທັນທີ ໂດຍບໍ່ຕ້ອງກົດປຸ່ມເພີ່ມ
- ຖ້າສະແກນສິນຄ້າຊໍ້າ ລະບົບຈະເພີ່ມຈໍານວນ `+1`
- ສາມາດເພີ່ມ/ຫຼຸດ/ລຶບສິນຄ້າໃນຕະກ້າໄດ້
- ໃສ່ສ່ວນຫຼຸດ ເລືອກວິທີຊໍາລະ ແລະຈໍານວນເງິນທີ່ຮັບ
- ກົດ `ບັນທຶກ / ປິ້ນບິນ` ເພື່ອບັນທຶກການຂາຍ, ຕັດສະຕ໋ອກ ແລະປິ້ນບິນ

## ສະຫຼຸບການຊໍາລະມື້ນີ້

ໜ້າ `/pos` ສະແດງກ່ອງສະຫຼຸບດ້ານເທິງ 4 ກ່ອງ:

- `ເງິນສົດມື້ນີ້` ລວມ `sales.netAmount` ຂອງບິນທີ່ `paymentMethod = CASH`
- `ເງິນໂອນມື້ນີ້` ລວມ `sales.netAmount` ຂອງບິນທີ່ `paymentMethod = TRANSFER`
- `ອື່ນໆມື້ນີ້` ລວມ `sales.netAmount` ຂອງບິນທີ່ `paymentMethod = OTHER`
- `ລວມ ... ບິນ` ລວມຍອດຂາຍ POS ມື້ນີ້ທັງໝົດ ແລະຈໍານວນບິນ

ຍອດທີ່ນັບແມ່ນຍອດສຸດທິຫຼັງຫັກສ່ວນຫຼຸດ (`netAmount`) ເພື່ອໃຫ້ກົງກັບເງິນທີ່ລູກຄ້າຈ່າຍຈິງ.

## ປະຫວັດບິນໜ້າຮ້ານ

ໜ້າ `/pos/history` ໃຊ້ເບິ່ງບິນຂາຍໜ້າຮ້ານທີ່ບັນທຶກແລ້ວ.

ຟີເຈີຫຼັກ:

- ຄົ້ນຫາຈາກເລກບິນ, ຊື່ສິນຄ້າ ຫຼື SKU
- ກອງຕາມວິທີຊໍາລະ: ທັງໝົດ, ເງິນສົດ, ເງິນໂອນ, ອື່ນໆ
- ກອງຕາມວັນທີ
- ສະຫຼຸບເງິນສົດ, ເງິນໂອນ, ອື່ນໆ, ຍອດລວມ, ຈໍານວນບິນ ແລະກໍາໄລ
- ກົດເບິ່ງລາຍລະອຽດບິນໄດ້
- ປິ້ນບິນຊໍ້າໄດ້
- ຍົກເລີກບິນ ຫຼື ບັນທຶກຄືນສິນຄ້າໄດ້; ລະບົບຈະຄືນສະຕ໋ອກຂອງບິນນັ້ນ ແລະບໍ່ນັບບິນນັ້ນເປັນຍອດຂາຍ

## ປິດຍອດປະຈໍາວັນ

ໜ້າ `/pos/closing` ໃຊ້ປິດຍອດຂາຍໜ້າຮ້ານປະຈໍາວັນ.

- ເລືອກວັນທີທີ່ຕ້ອງການປິດຍອດ
- ສະແດງຍອດເງິນສົດ, ເງິນໂອນ, ອື່ນໆ, ຈໍານວນບິນ ແລະກໍາໄລ
- ກອກເງິນສົດທີ່ນັບໄດ້ຈິງ
- ລະບົບຄໍານວນສ່ວນຕ່າງລະຫວ່າງເງິນສົດຕາມລະບົບ ແລະເງິນສົດທີ່ນັບໄດ້
- ບັນທຶກໝາຍເຫດປະຈໍາວັນໄດ້

ຂໍ້ມູນປິດຍອດເກັບໃນ local store ເຊັ່ນດຽວກັບ settings/logo ເພື່ອໃຫ້ໃຊ້ໄດ້ທັນທີໃນໂໝດ dev.

## ໃບບິນ

ໃບບິນ POS ໃຊ້ຂະໜາດ `80mm` ເໝາະກັບເຄື່ອງປິ້ນໃບເສັດຮ້ອນ. ຟອນໃນໃບບິນໃຊ້ `Noto Sans Lao` ຈາກ `public/fonts`.

ໃບບິນທີ່ໃຫ້ລູກຄ້າຈະບໍ່ສະແດງ SKU / Barcode ເພື່ອໃຫ້ບິນອ່ານງ່າຍ. SKU / Barcode ຍັງເກັບໄວ້ໃນລະບົບສໍາລັບສະແກນ, ຄົ້ນຫາ ແລະກວດສະຕ໋ອກ.

ຫົວໃບບິນ POS ໃຊ້ຂໍ້ມູນຊຸດແຍກໃນ `Settings > ບິນຂາຍໜ້າຮ້ານ`:

- `posReceiptName`
- `posReceiptSubtitle`
- `posReceiptNote`
- `posReceiptLogoUrl`

ຂໍ້ມູນຊຸດນີ້ບໍ່ກະທົບໃບບິນຂົນສົ່ງຂອງອໍເດີອອນລາຍ.
