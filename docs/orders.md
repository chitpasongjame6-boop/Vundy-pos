# Orders Module

## Print Bill Note

- ປຸ່ມ `ປິ້ນບິນ` ໃນປະຫວັດອໍເດີໃຊ້ຂໍ້ມູນຈາກອໍເດີທີ່ກົດເທົ່ານັ້ນ: ຊື່ລູກຄ້າ, ເບີຜູ້ຮັບ, ຂົນສົ່ງ, ສາຂາ, ເມືອງ, ແຂວງ, ສະຖານະ COD.
- ຂະໜາດບິນປິ້ນເປັນ `100mm x 150mm` ແລະຕັ້ງ `@page` ໃຫ້ print preview ມອງເປັນກະດາດຂະໜາດນີ້.
- ກອບບິນສູງຕາມຂໍ້ມູນຈິງ ເພື່ອບໍ່ໃຫ້ມີຊ່ອງວ່າງໃນກອບດ້ານລຸ່ມ; ກະດາດ print ຍັງເປັນ `100mm x 150mm`.
- ວັນທີ ເດືອນ ປີ ແລະເວລາ ສະແດງຕົວນ້ອຍຢູ່ມຸມຊ້າຍເທິງຂອງບິນ ໂດຍໃຊ້ຮູບແບບ `10/5/2026 17:25`.
- ໜ້າປິ້ນບິນບັງຄັບ font `Noto Sans Lao` ກັບທຸກ element ໂດຍໃຊ້ໄຟລ໌ local ໃນ `public/fonts`; ກ່ອນ print ຈະລໍຖ້າ font weights ທີ່ໃຊ້ໂຫຼດໃຫ້ພ້ອມກ່ອນ.
- ໜ້າປິ້ນບິນຈະລໍຖ້າໂລໂກ້ໂຫຼດໃຫ້ສໍາເລັດກ່ອນເປີດ print dialog; ຖ້າຮູບໂຫຼດຊ້າເກີນ 2 ວິນາທີ ຈະເປີດ print dialog ຕໍ່ໄປເພື່ອບໍ່ໃຫ້ຄ້າງ.
- ຖ້າ browser ຫຼື mobile mode ບລັອກ popup ລະບົບຈະພິມບິນຜ່ານ iframe ທີ່ຊ່ອນໄວ້ ເພື່ອບໍ່ໃຫ້ພິມໜ້າປະຫວັດທັງໜ້າ.
- ຂໍ້ຄວາມຫົວບິນເຊັ່ນ ຊື່ຮ້ານ, ຂໍ້ມູນແຖວ 2 ແລະ ແຖວ 3 ມາຈາກໜ້າ `Settings`.

## ສະຖານະອໍເດີ

- `PENDING_PACK` ລໍຖ້າແພັກ ສີເຫຼືອງ
- `PACKED` ແພັກແລ້ວ ສີຟ້າ
- `SHIPPED` ສົ່ງແລ້ວ ສີຂຽວ
- `CANCELLED` ຍົກເລີກ ສີເທົາ
- `RETURNED` ຕີກັບ ສີແດງ

## ຟີເຈີທີ່ເຮັດແລ້ວ

- ສະແດງລາຍການອໍເດີແບບກ່ອງ card
- ໜ້າອໍເດີຫຼັກ ແລະ ໜ້າປະຫວັດອໍເດີກົດ card ແລ້ວເປີດລາຍລະອຽດໃນ popup/modal ເພື່ອບໍ່ໃຫ້ໜ້າຍາວເກີນໄປ
- ລວມທີ່ຢູ່ ແລະ ບໍລິສັດຂົນສົ່ງໄວ້ໃນຊ່ອງດຽວເພື່ອໃຫ້ອ່ານງ່າຍ
- ຊຸດຄົ້ນຫາໃນໜ້າປະຫວັດອໍເດີມີ: ຄົ້ນຫາ, ກອງໝວດໝູ່, ກອງສະຖານະຈັດສົ່ງ, ເລືອກວັນທີ, ແລະປຸ່ມຄົ້ນຫາ
- ຄົ້ນຫາປະຫວັດອໍເດີຈາກຊື່ລູກຄ້າ ເບີໂທ ແລະ SKU
- ກອງປະຫວັດອໍເດີຕາມໝວດໝູ່ສິນຄ້າ
- ກອງປະຫວັດອໍເດີຕາມສະຖານະໄດ້ ເຊັ່ນ `PENDING_PACK` ເພື່ອຫາອໍເດີທີ່ລືມແພັກ
- ກອງປະຫວັດອໍເດີຕາມວັນທີໄດ້ ໂດຍເລືອກວັນຈາກ input ແລ້ວລະບົບຈະສະແດງສະເພາະອໍເດີຂອງມື້ນັ້ນ
- ຟອມສ້າງອໍເດີ
- ຕອນເລືອກສິນຄ້າໃນອໍເດີ ລະບົບຈະໃຫ້ເລືອກຂະໜາດ/variant ເຊັ່ນ 10ml ຫຼື 20ml
- ໜ້າສ້າງອໍເດີມີຊ່ອງ `ສະແກນ SKU / Barcode`; ເມື່ອສະແກນກົງກັບ SKU ຂອງ variant ລະບົບຈະເລືອກສິນຄ້າ/ຂະໜາດໃຫ້ອັດຕະໂນມັດ
- ຊ່ອງສະແກນຈະກັນປຸ່ມ Enter ຈາກເຄື່ອງສະແກນ ເພື່ອບໍ່ໃຫ້ຟອມ submit ກ່ອນກອກຂໍ້ມູນຄົບ
- ຟອມສ້າງອໍເດີມີຊ່ອງ `ສາຂາຮັບເຄື່ອງ`
- ຟອມສ້າງອໍເດີມີ dropdown `ການຊໍາລະ` ເລືອກ `ຈ່າຍແລ້ວ` ຫຼື `COD / ເກັບເງິນປາຍທາງ`
- ກວດສະຕ໋ອກກ່ອນສ້າງອໍເດີ
- ຄໍານວນຍອດຂາຍ ຕົ້ນທຶນ ແລະ ກໍາໄລ
- ຕັ້ງສະຖານະຫຼັງສ້າງອໍເດີເປັນ `PENDING_PACK`
- ຕັດສະຕ໋ອກເມື່ອບັນທຶກລົງຖານຂໍ້ມູນຈິງ
- popup ລາຍລະອຽດອໍເດີມີປຸ່ມປ່ຽນສະຖານະ `PENDING_PACK`, `PACKED`, `SHIPPED`, `CANCELLED`
- ການຕີກັບ `RETURNED` ໃຊ້ຟອມແຍກ ເພື່ອບັນທຶກເຫດຜົນ ແລະ ໝາຍເຫດຕີກັບ
- ອໍເດີທີ່ `RETURNED` ຈະມີປຸ່ມຮັບສິນຄ້າຄືນເຂົ້າສະຕ໋ອກ 1 ຄັ້ງ; ຫຼັງຈາກຮັບຄືນແລ້ວຈະບັນທຶກ `restockedAt`
- ໜ້າປະຫວັດອໍເດີມີປຸ່ມແກ້ໄຂຂໍ້ມູນລູກຄ້າ ທີ່ຢູ່ ຂົນສົ່ງ ສາຂາຮັບເຄື່ອງ ແລະ ໝາຍເຫດ
- ໜ້າປະຫວັດອໍເດີມີປຸ່ມ `ປິ້ນບິນ` ເພື່ອພິມສະເພາະຂໍ້ມູນຂົນສົ່ງ: ໂລໂກ້, ຊື່ຮ້ານ, ຊື່ຜູ້ຮັບ, ເບີຜູ້ຮັບ, ຂົນສົ່ງ, ສາຂາ, ເມືອງ, ແຂວງ
- ບິນຈະສະແດງກ່ອງ `COD` ແລະຍອດເງິນສະເພາະອໍເດີທີ່ເລືອກ `COD`; ຖ້າເລືອກ `ຈ່າຍແລ້ວ` ຈະບໍ່ສະແດງໃນບິນ
