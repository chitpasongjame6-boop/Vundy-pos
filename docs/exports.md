# Export Data

ໜ້າ `/exports` ໃຊ້ລວມຂໍ້ມູນສໍາຄັນຂອງລະບົບໄວ້ໃນໜ້າດຽວ ເພື່ອພິມ ຫຼື Save PDF.

## ຂໍ້ມູນທີ່ Export

- ສິນຄ້າ ແລະ variant/ຂະໜາດ: SKU, ຊື່, ໝວດໝູ່, ຕົ້ນທຶນ, ລາຄາຂາຍ, ສະຕ໋ອກ
- ອໍເດີອອນລາຍ: ເລກອໍເດີ, ວັນທີ, ລູກຄ້າ, ເບີ, ຂົນສົ່ງ, ສະຖານະ, ລາຍການສິນຄ້າ, ຍອດຂາຍ, ກໍາໄລ
- ບິນຂາຍໜ້າຮ້ານ: ເລກບິນ, ວັນທີ, ສະຖານະ, ວິທີຊໍາລະ, ລາຍການສິນຄ້າ, ຍອດສຸດທິ, ກໍາໄລ
- ປະຫວັດປິດຍອດ: ເລກປິດຍອດ, ວັນທີ, ເງິນສົດ, ເງິນໂອນ, ຍອດລວມ, ເງິນສົດຈິງ, ສ່ວນຕ່າງ, ໝາຍເຫດ

## Font

ໜ້າ Export ໃຊ້ font `Noto Sans Lao` ຈາກ layout ກາງຂອງລະບົບ. ເມື່ອກົດ `ພິມ / Save PDF`, browser ຈະໃຊ້ font ດຽວກັນໃນເອກະສານ.

## ເລກເອກະສານ

ອໍເດີໃໝ່ຈະໄດ້ເລກຮູບແບບ `ORD-YYYYMMDD-001`.

ບິນ POS ໃໝ່ຈະໄດ້ເລກຮູບແບບ `POS-YYYYMMDD-001`.

ປິດຍອດປະຈໍາວັນຈະໄດ້ເລກຮູບແບບ `CLS-YYYYMMDD`.
