## ຟີເຈີທີ່ເຮັດແລ້ວ

- ສະແດງຍອດຂາຍເດືອນນີ້
- ສະແດງກໍາໄລເດືອນນີ້
- ສະແດງອັດຕາກໍາໄລ
- ແຍກຍອດຂາຍເດືອນນີ້ເປັນ ອອນລາຍ, ຂາຍໜ້າຮ້ານ, ລວມທັງໝົດ
- ສະແດງກຣາຟຍອດຂາຍ ແລະ ກໍາໄລລາຍວັນ
- ນັບຍອດຂາຍໜ້າຮ້ານ POS ຈາກ `sales.netAmount` ລວມກັບອໍເດີອອນລາຍທີ່ `SHIPPED`

```text
ຍອດຂາຍ = ລາຄາຂາຍ x ຈໍານວນ

```
